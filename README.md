# NOVA HUB v0.2 — Android

Красно-чёрный мини-хаб для NOVA: Forsaken NOVA, Clash Helper и будущих инструментов.

## Уже работает

- Главная, модули, журнал обновлений, лаборатория и настройки.
- Красно-чёрный готический интерфейс, адаптация под телефон и планшет.
- Проверка версий через файлы `nova-hub.json` **в двух существующих репозиториях**.
- Копирование последнего `nova.lua` с GitHub в буфер Android.
- Офлайн-кэш метаданных и однажды скопированного скрипта.
- Запуск установленного Clash Helper (`dev.novaroyale.tracker`) из Hub.
- Открытие GitHub и страницы сборок Clash Helper.
- Кнопка ручной проверки обновлений.

## Ограничения

- Скрипт Forsaken не выполняется внутри Hub: доступны отдельные кнопки для стабильной и тестовой версий.
- Clash Helper — **отдельный Android APK**, который Hub запускает. Встроенный оверлей ещё не готов.
- Для проверки версий нужен интернет; при отсутствии сети видны ранее сохранённые данные.
- Версии скрипта и помощника обновляются через GitHub без обновления APK, но **изменения в самом интерфейсе Hub требуют новой сборки APK**.
- Автоматически слушать разговоры ChatGPT приложение не умеет; нужные изменения должны попадать в GitHub.

## Сборка через GitHub Actions (без компьютера)

1. Создать **новый, отдельный** репозиторий `nova-hub` на GitHub (не класть проект в `nova-forsaken` или `nova-royale`).
2. Загрузить в корень репозитория содержимое архива `NovaHub-v0.1-source.zip` (файлы `build.gradle.kts`, `settings.gradle.kts`, папки `app` и `.github` и т.д.).
3. На вкладке **Actions** открыть `Build Nova Hub APK`, запустить **Run workflow** (или дождаться первой сборки при push на main).
4. В завершённом прогоне скачать артефакт `Nova-Hub-v0.1-debug-APK`, распаковать ZIP и установить `app-debug.apk`.

GitHub Actions использует Temurin Java 17, Android SDK 35, Gradle 8.11.1, Android Gradle Plugin 8.9.2. Версия Android: 8.0+.

## Обновление скрипта из другого чата

Для публикации версии Forsaken NOVA в `Trotilov/nova-forsaken` обновить **два файла**:
- `nova.lua` — полный актуальный Lua-скрипт;
- `nova-hub.json` — номер версии и пункты `changelog` (поле `script_url` оставить прежним).

При следующей синхронизации Nova Hub увидит обновлённый JSON, а кнопка «Скопировать» загрузит свежий `nova.lua`.

Для Royale — обновить `Trotilov/nova-royale/nova-hub.json` после реального релиза сборки. Новые APK получаются отдельно, через Actions/релизы, и устанавливаются обычным способом.

## Как проверить интерфейс без Android

Открыть `app/src/main/assets/index.html` в браузере или прилагаемый `NovaHub-v0.1-preview.html`. В обычном браузере нельзя запускать сторонние Android-приложения. GitHub-запросы могут блокироваться настройками браузера/файловыми ограничениями, но статический интерфейс работает и офлайн.

## Безопасность

Android WebView показывает только локальные упакованные assets. Внешние ссылки открываются в системном браузере. Скрипт загружается только с жёстко заданного пути в репозитории Forsaken NOVA; Hub не выполняет скрипты и не запрашивает доступность экрана/Accessibility/оверлея.
